
# Airport Operations Backend Simulator

## Project Goal

Build a practical airport operations system using Linux, Python, and a database.

## Features

- Display fictional flight information
- Store flight records
- Monitor application health
- Practice Linux system administraion
- Automate tests using DevOps tools


## Technology

- Rocky Linux
- Python
- MariaDB (planned)
- GitHub Actions (planned)

## Safety

This is an educational simulator using fictional flight data. It does not connect to real airport systems or control aircraft.
